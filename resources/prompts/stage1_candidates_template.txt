WHAT THE LABEL MEANS

- The root is the major misconception that the rest of the working follows from. It is not necessarily the first error written, and not necessarily the step that produced the final wrong number.
- A major error changes the reasoning or the result. Arithmetic or copying slips (CAL-01) can be the root when they change the result.
- NONE means fully correct working, or only minor slips that do not change the result (for example, imprecise notation, a slip not carried forward, an abandoned and corrected attempt, or an equivalent but differently formatted final answer).
- Exactly one code is the root. Your list holds alternative possible roots, not simultaneous findings.

CODES THAT ARE EASY TO OVERLOOK

These notes add candidates to consider. They never rule a code out, and the taxonomy definitions remain the authority.
- If the error belongs to a specific topic (shape formulas, statistics, KPK/FPB, counting and probability, inverse functions), list the topic code and also FRM-01. If no code describes the error, consider OTH-00.
- If a value the student computed correctly is then processed further although it already answers the question, or is reported as a different quantity, consider ANS-02. If the work stops at a correct intermediate value, consider ANS-01.
- If a given number from a word problem is used in a role it does not play, or a distractor value is used, consider WOP-02 alongside WOP-01.
- If a power appears to be evaluated as base × exponent (for example r² taken as r × 2), consider EXP-01.
- For errors with roots or radicals, list both EXP-04 and EXP-07.
- For exponent-law errors, consider EXP-02. If a zero exponent is evaluated as the base or as 0, consider EXP-05.
- If a multiplier or divisor reaches only some of the terms, consider ALG-04. If an operation is applied to one side of an equation only, consider ALG-05. If a term crosses the equals sign without its sign or operation changing, consider ALG-06.
- If a − (−b) appears, consider INT-03. If a sign is dropped, flipped or reversed, consider INT-04.
- If fraction-addition mechanics (a common denominator, cross-multiplying) appear in a fraction multiplication task, consider FRA-06. If digits or terms are struck out across a sum, consider FRA-04.
- If a value appears to be misread from a figure, table or chart, consider VIS-01. If a number is miscopied between the student's own lines, consider CAL-01.
- If the photo shows work for a different problem, or no handwritten working by the student on this question, consider REL-01.
- If the question involves KPK or FPB, consider the KPF codes alongside FRM-01 and CAL-01.

HOW TO REASON

Before you answer, reason through the case in this order. Do not write this analysis in your answer; only the JSON below is returned.

1. What the student actually did. Go block by block and line by line. Describe the operations and values on the page, from the image where it differs from the transcriptions. Note crossed-out or abandoned work, and say which readings you are unsure of and why.
2. Where it departs from a correct solution. Compare with the reference working, allowing for valid alternative methods. Identify each departure, and say whether it is major (it changes the result) or minor.
3. How the departures relate. Say which departure the others follow from, and which are independent. If a later error is only a consequence, say so.
4. Which codes could describe the root. For each plausible root, name every code an annotator might reasonably choose for it: the topic-specific code, the general code that would also fit, and close neighbours whose definitions differ only slightly. The code pairs named in this prompt are examples, not a complete list of confusable codes. Argue the comparisons in your own words. For example:
   - "Both WOP-01 and FRA-06 fit; FRA-06 names the procedure actually used (fraction addition mechanics in a multiplication task), so it is more specific."
   - "ALG-05 would have to be stretched: this is a one-sided expression, and nothing is moved across an equals sign. ALG-04 matches what is on the page: the conjugate is applied to the denominator only."
   - "The method is right up to the last line; the only fault is a dropped sign, so a method-level code should not lead."
   - "7 × 8 = 54 appears once while 56 is used correctly elsewhere; that is a slip, not a belief."
   - "The transcription shows 2x² but the handwriting could be 2x 2; if so, the exponent code disappears."
   Label what the student did, not every gap it might imply.
5. Whether the working could be NONE. Consider this explicitly, even when the final answer is wrong or missing, and say why it does or does not apply.
6. Whether an alternative reading changes the codes. For each uncertain reading that matters, say which codes it would bring in.

BE INCLUSIVE IN THE CANDIDATE LIST

Missing the true code is the costly error at this stage. A too-long list is cheap. Include:
- every code you would seriously consider as the root;
- the specific and the general code for the same mechanism (for example FRA-06 and WOP-01, MEA-04 and FRM-01, EXP-04 and EXP-07, WOP-01 and WOP-02);
- codes that would apply under a plausible alternative reading of the handwriting;
- NONE, whenever the errors you found might be judged minor;
- a code for a different departure, if an annotator could reasonably treat that one as the root instead.

Do not add codes with no connection to what is on the page. Return at least 5 and at most 10 distinct codes, ordered from most to least likely to be the annotated root. Even when the case looks clear-cut, fill the list to at least 5 with the next most plausible alternatives (for example NONE, the general code for the same mechanism, a close neighbour, or a code for a different departure), still in order of likelihood.
